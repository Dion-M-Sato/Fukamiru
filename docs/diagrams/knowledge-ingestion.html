Knowledge Search · 検索レポート

本文・書誌から候補を検索 → 関連資料・人物を選別 → 前後の本文を読む → 原資料で書誌を照合 → 論点をつないで報告 → 主張・引用・使用書誌を再検査 → 報告を保存 → クリックで右ペイン表示

本文と書誌から候補を探し、人名の混同・重複・索引・献辞を選別します。前後の本文を読み、論点をつないだ文章として報告します。gpt-5.6-sol / medium。使用した文献だけを原資料の書誌ページ・画像で照合し、本文の主張と書誌を独立に再検査。原文にない引用や表題紙だけの内容説明は拒否します。OCRで見出しが落ちた目次や書誌カバーも本文から除外。著者名の展開は完全な名前の原文引用を要求し、書誌・報告は各1回だけ訂正できます。独立再検査では留保も確認し、読取前の計画や内部状態は完成報告に表示しません。確認済みHTML・使用文献・本文の根拠・採否記録をstate.dbに保存。knowledge.dbの原資料は保持します。根拠不足なら理由を示し、検査失敗時は保存しません。一覧から右ペインで再読し、HTMLを保存できます。取り込みRunは開始しません。
